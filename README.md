# معلم البرمجة الاحترافي 🧩

موقع تفاعلي لتعليم أوامر البرمجة في MIT App Inventor للطالبات من الصفر حتى المخرجات.

🌐 الموقع بعد النشر سيكون على GitHub Pages.

## التشغيل محلياً
افتح ملف `index.html` في المتصفح مباشرة.

## المميزات
- شرح من الصفر حتى تصدير APK
- موسوعة 9 عائلات بلوكات بألوان App Inventor
- مختبر بلوكات + محاكي هاتف + اختبار 10 أسئلة + شهادة
- خيارات عرض: تكبير الخط، غامق، ليلي/نهاري
